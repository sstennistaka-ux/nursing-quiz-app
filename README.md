# 看護師特定行為研修 クイズアプリ

ブラウザだけで動く、Excelファイルをインポートして使うクイズ学習アプリです。サーバー不要・単一の `index.html` のみで動作し、データはすべてブラウザの localStorage に保存されます（外部送信は一切ありません）。

このリポジトリには問題データは含まれていません。著作権の関係で、実際の問題（日本看護協会のeラーニング教材等に基づくもの）は同梱せず、各自でお手元のExcelファイルをインポートして使用してください。

## 使い方

1. [index.html](index.html) をブラウザで開く（GitHub Pagesで公開している場合はそのURLにアクセス）。
2. 「Excelをインポート」からお手元の `.xlsx` ファイルを選択する。
3. 同じファイル名で再インポートすると内容が更新され、新しいファイル名なら追加登録されます（最大25件）。

## Excelファイルの形式

1行目はヘッダー行（読み飛ばされます）。2行目以降が問題データです。列の並びは以下の通りです。

| 列 | 内容 | 例 |
|---|---|---|
| A | ID | 1 |
| B | 中分類（カテゴリ） | 病理学総論 |
| C | 問題文 | 病理診断に必要なものは次のうちどれか。 |
| D〜H | 選択肢 A〜E（使わない場合は空欄可） | 年齢・性別 / 臨床経過 / … |
| I | 正答（1始まりの番号。複数正解は `1,3` のようにカンマ区切り） | 1 または 1,3 |
| J | 解説（任意） | 〜のため。 |

## 主な機能

- ファイルごとのクイズ出題、全ファイル横断の「認定審査チャレンジ」（ランダム20問）
- 間違えた問題を自動収集する「弱点集」（正解すると自動的に弱点集から外れます）
- クイズの「中断」機能と、ファイル一覧からの「最初から／続きから」の再開選択
- ファイルごとの達成度（累計で一度でも正解した問題の割合）表示

## 開発

単一の静的HTMLファイルです。ビルド手順は不要で、`index.html` を直接編集・保存すればそのまま動作します。
